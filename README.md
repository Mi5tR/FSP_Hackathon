# ФСП Карьера

Платформа подбора ИТ-специалистов с обратной механикой: кандидат проходит адаптивный тест и получает категорию,
а работодатель находит категорию и сам приглашает кандидата, сразу указывая вилку зарплаты.

* **Соответствие ответам постановщиков и обязательному перечню: [docs/09-requirements-trace.md](docs/09-requirements-trace.md)**
* Концепция и механики: [docs/01-concept.md](docs/01-concept.md)
* Отчёт валидации: [docs/02-validation.md](docs/02-validation.md)
* Архитектура: [docs/05-architecture.md](docs/05-architecture.md), интеграция с ФСП ID: [docs/06-fsp-integration.md](docs/06-fsp-integration.md)
* API: [docs/07-api.md](docs/07-api.md), Swagger http://localhost:8000/docs; библиотеки: [docs/08-libraries.md](docs/08-libraries.md)
* Развёртывание на сервере: [docs/04-deploy.md](docs/04-deploy.md)
* Презентация: [docs/ФСП_Карьера_презентация.pptx](docs/ФСП_Карьера_презентация.pptx), вся документация одним файлом: [docs/ФСП_Карьера_документация.docx](docs/ФСП_Карьера_документация.docx)
* ТЗ, ответы на вопросы и шаблон презентации: папка `materials/`

## Запуск через Docker

```bash
docker compose up --build
```

* Приложение: http://localhost:8080 (порт меняется переменной `FRONTEND_PORT`, например в файле `.env`:
  `FRONTEND_PORT=8090` и `FRONTEND_URL=http://localhost:8090`)
* Swagger: http://localhost:8000/docs
* Письма подтверждения (Mailpit): http://localhost:8025

Демо-данные загружаются автоматически. Пароль у всех демо-аккаунтов: `demo12345`.

| Аккаунт | Роль |
|---|---|
| `candidate@demo.ru` | кандидат без теста, чтобы пройти путь с нуля |
| `cand3@demo.ru` | кандидат с категорией, достижениями ФСП, приглашениями и перепиской |
| `employer@demo.ru` | работодатель «Цифровой Банк»: вакансии, приглашения до оффера и выхода, подключённый Huntflow (демо-режим) |
| `cand0@demo.ru` … `cand499@demo.ru` | 500 кандидатов 8 специализаций и 6 грейдов; у части есть ФСП, у части грейд не подтверждён, `cand7` — 16 лет |
| `hr@retail.demo.ru`, `hr@mobilab.demo.ru`, `hr@datapulse.demo.ru`, `hr@cybershield.demo.ru` и др. | другие работодатели (всего 10) |
| `start.career.hr@mail.demo.ru` | компания, приостановленная по жалобам кандидатов (демонстрация антифрода) |

**Без регистрации:** на странице входа есть «Быстрый вход» — создаёт чистый аккаунт соискателя или работодателя,
чтобы самому пройти тест и подбор с нуля. **Вход через ФСП ID** — имитация Keycloak: логин вида `FSP-102347`
(ID на `0` — участник без истории) или email, пароль `demo12345`. Подробнее — [docs/06-fsp-integration.md](docs/06-fsp-integration.md).

Обновление кода не требует пересоздавать базу: недостающие колонки добавляются при старте (`ensure_columns`).

## Локальный запуск без Docker

Требуются Python 3.12+ и Node 20+.

```bash
cd backend
pip install -r requirements.txt
python -m app.seed.demo            # SQLite-файл fsp_talent.db
uvicorn app.main:app --port 8000

cd ../frontend
npm install
npm run dev                         # http://localhost:5173, /api проксируется на :8000
# другой порт бэкенда: API_TARGET=http://127.0.0.1:8001 npm run dev
```

Без SMTP ссылка подтверждения пишется в лог бэкенда, а в `DEV_MODE=1` токен приходит в ответе регистрации
(на экране есть кнопка «подтвердить сразу»).

Новые поля моделей добавляются в существующую базу автоматически при старте. Чтобы получить свежие демо-данные,
удалите `backend/fsp_talent.db` (или выполните `docker compose down -v`) и снова запустите `python -m app.seed.demo`.

## Тесты и валидация

```bash
cd backend
python -m pytest -q          # сквозной сценарий ТЗ, требования из Q&A, оффер, жалобы, ATS, ML (26 тестов)
python -m scripts.validate   # симуляция: пишет docs/02-validation.md и app/services/matching/calibration.json
```
